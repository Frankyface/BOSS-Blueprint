# BOSS Blueprint

**Sketch your website. We build it.**

BOSS Blueprint is a free, browser-based design tool from [BOSS](https://bossolutions.pro).
Lay out your future website like a slide deck — drag in sections, headings, text, images and
buttons, scribble notes with the pen tool, add as many pages as you need, and wire up the
navigation. When you're happy, hit Submit: your design goes straight to the BOSS team, who
build the real website exactly the way you laid it out.

- No account, no install — runs in your desktop browser
- Start from a template (Restaurant, Trades, Portfolio, Shop) or a blank page
- Your draft autosaves in your browser; you can also download it as a file and come back later
- Don't have the words yet? Drop a placeholder describing what the text should say — we write it

Built with React + TypeScript. Hosted on GitHub Pages.
